# A page about Setara for the Humanitäre Hilfe Afghanistan website

This is a handover for whoever maintains the website. It is a draft: the
page is **not to be published** until Joel has seen it on a private preview.

## What is wanted

1. A page about Setara on the site, in the site's languages, in the site's
   own design.
2. On that page, a way to give money for more devices, using the donation
   route the site already has (bank details, payment link, whatever is in
   use). The amounts below are suggestions to pair with it.
3. A private preview first (tailnet only, no public link, not in the menu,
   `noindex`).

## Facts the page may state

- Setara is an offline learning app on a small game handheld, made for
  village classrooms in Afghanistan, in Dari.
- One device with a loudspeaker serves a teacher and a class of up to 50.
  Children can also learn alone or in pairs.
- Subjects: English, reading Dari, math, health (including first aid).
- It needs no internet and stores no personal data: no names, no photos.
- It is open source and free for others to reuse and translate.
- It is a prototype. The software runs on a computer; the first test devices
  and the review by Dari-speaking teachers and a health professional come
  next. **Do not say or suggest that children are already using it.**

## Costs (estimates from the project plan, November 2026; not quotes)

| What | About |
| --- | --- |
| One handheld for learners | CHF 35 to 50 |
| One classroom kit: handheld, loudspeaker, solar panel and power bank, memory card, sleeve | CHF 90 to 130 |
| A pilot in five classrooms, with spares | CHF 1,500 to 3,000 |

Suggested giving steps: **CHF 50** one more device for a class; **CHF 120**
a whole classroom kit; **CHF 600** five classrooms. Say plainly that these
are estimates and that money given for Setara is used for devices,
loudspeakers, solar chargers, memory cards and getting them to the
classrooms. If the association cannot earmark donations, say that instead.

## Things to be careful with

- No photos of children or teachers, no names of villages or schools.
- Girls' schooling is sensitive where the programme works. The page talks
  about children and classrooms; it does not single out girls' classes or
  say where devices go.
- No claims about results. Nothing has been measured yet.
