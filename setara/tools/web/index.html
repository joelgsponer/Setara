Source on GitHub

An offline learning app for village classrooms, shown here in a browser so that it can be tried. The product itself runs on a small game handheld. This page starts in English mode: the children hear Dari, and what is spoken appears as an English caption under the screen.

This is a prototype. The content is a first draft that no Dari-speaking educator or health professional has reviewed yet, and the voices are placeholders. Nothing you do here is sent anywhere: the page works offline once loaded and stores only stars and settings in your browser.
